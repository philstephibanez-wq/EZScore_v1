# Recette ciblée R23 — STEMS ONLY

## Objectif

Valider uniquement la séparation audio.

Aucune autre analyse musicale n'est autorisée dans ce lot.

## Test recommandé

Utiliser successivement :

- Tombe la neige
- Susanna
- La Bohème

Pour chaque morceau :

1. Ouvrir le workspace.
2. Ouvrir `1 · STEMS`.
3. Cliquer `Séparer les STEMS`.
4. Lancer le worker.
5. Suivre la progression.
6. Écouter séparément les 8 sorties.
7. Vérifier la séparation chant principal / chœurs.
8. Vérifier guitare / piano / basse / batterie.
9. Cliquer `Réanalyser les STEMS`.
10. Vérifier qu'en cas de succès le nouveau run devient courant.
11. Vérifier qu'un échec volontaire ne détruit pas l'ancien run.

## Interdit pendant cette recette

Ne pas tester / brancher :

- paroles
- accords
- rythme
- blocs
- MIDI
- karaoké
